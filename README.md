# S&P 500 Stock Market Analytics & Price Prediction

## Project Overview

This project analyzes historical **S&P 500 stock prices (2014–2017)** using **Python and Jupyter Notebook**. The goal is to identify market trends, analyze volatility, engineer predictive features, and forecast future stock prices.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* XGBoost
* Statsmodels

## Main Tasks

* Data loading and cleaning
* Exploratory Data Analysis (EDA)
* Feature engineering
* Volatility analysis
* Regression modeling
* Feature importance analysis
* ARIMA time-series forecasting
* Business insights generation

## Models Used

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor
* XGBoost Regressor

## Conclusion

The project shows that S&P 500 stocks experienced **overall positive long-term growth**, while the **Random Forest model achieved the strongest predictive performance** among the evaluated regression models.
